# Recommendation System

## 📌 Overview
This project is a simple content-based recommendation system that suggests movies based on user preferences. It demonstrates core recommendation logic and data handling.

## 🎯 Objectives
- Provide personalized recommendations
- Improve user experience
- Simulate real-world recommendation logic

## 🧩 Features
- Genre-based filtering
- Dynamic user input
- Clean modular design

## 🛠 Tech Stack
- Python

## 📂 Structure
- main.py → Entry point
- recommender.py → Logic
- data.py → Dataset
- test_recommender.py → Unit testing

## ▶️ How to Run
python main.py

## 🧪 Testing
python test_recommender.py
